# Codex / Probe 사용 안내

원본: https://github.com/anthropics/knowledge-work-plugins
고정 버전: `2574e29377c7173d0cecffef29a6ecbd7f8ccb5d` · `data/LICENSE`의 Apache-2.0 적용.
2026-10-31: Codex 호출·참고 링크·한국어 해커톤 안내를 추가한 배포본이다.

- `$스킬이름 요청`으로 사용한다. 한국어 요청에는 한국어로 설명한다. 원본의 `/명령`은 호스트별 예시이며 별도 슬래시 명령을 설치한 것이 아니다.
- 원본의 데이터·수치·회사 예시는 설명용이다. 실제 제공된 파일과 실행 결과를 근거로 사용하고, 원본 데이터가 없으면 검증할 수 없는 부분을 표시한다.
- 로컬 CSV·Excel·JSON 등으로도 사용할 수 있다. 창고 연결이나 별도 Claude 플러그인을 필수로 요구하지 않는다. 연결된 도구가 있을 때만 해당 기능을 사용한다.
- 기존 Python/분석 환경을 우선한다. CSV는 표준 라이브러리로도 확인할 수 있고, 필요할 때 pandas·openpyxl·matplotlib·seaborn·plotly 등을 준비한다. 설치만으로 도구 준비가 완료된 것은 아니다.
- 전체 파일과 표본을 구분한다. 결측률·상관계수 같은 원본의 임계값은 탐색용 예시이며 현업 합격 기준이 아니다. 결측 원인을 확인하지 않고 자동 대체·삭제하지 않는다.
- 비율·변화율·금액의 허용 범위는 지표 정의에 따른다. 변화율이 100%를 넘거나 순금액이 음수인 것만으로 오류라고 판정하지 않는다. 분모와 기간·단위·업무 시간대를 먼저 확인한다.
- 기존 `probe-notes/brief.md`, `decisions.md`, `evidence.md` 또는 프로젝트 기록에 근거를 연결한다. 데이터를 외부에 공개하거나 자동 전송하는 작업은 포함하지 않는다.

## 이 스킬을 쓸 때

검증한 분석 수치를 발표용 차트로 만들 때 사용한다. 작업 현황판은 `visual-explainer`, 편집 가능한 PPT 조립은 `slides`가 담당할 수 있으나 이 스킬만 단독으로 써도 된다.

- 차트 제목이 데이터보다 강한 인과관계나 효과를 주장하지 않게 한다. 출처·기간·단위·표본 크기와 필터를 함께 남긴다.
- 표본이 없으면 ‘데이터 없음’을 표시한다. 원본 예시 코드는 필요한 데이터프레임과 열이 준비됐다는 가정이므로 실제 데이터에 맞춰 확인한다.
- 한국어 글꼴이 설치돼 있는지 확인하고 저장한 그림을 열어 글자 깨짐·잘림을 검사한다. 화면 검사를 못 했다면 미실행으로 표시한다.
- PNG/SVG/PDF와 재생성 코드·집계표를 함께 남길 수 있다. 이미지로 넣은 PPT 차트가 편집 가능한 차트라고 주장하지 않는다. 편집이 필요하면 `slides`에 집계표를 넘겨 네이티브 차트로 만든다.

요청 예: `$data-visualization 검증된 결과로 발표용 차트를 만들고, 출처·기간·단위·표본 수를 표시해줘. 한국어 표시와 잘림도 확인해줘.`
