# Codex / Probe 사용 안내

원본: https://github.com/wshobson/agents/tree/main/plugins/llm-application-dev/skills/llm-evaluation
고정 버전: `0874a27b17a22e2b7c2e2bcd725768e0803cad06` · MIT, Seth Hobson.
2026-10-31: MVP 평가 절차와 예제 코드의 한계를 추가하고, 특정 호스트·모델을 기본 요구로 삼지 않도록 안내했다.

대상은 참가자가 만든 챗봇·검색·요약 등 **제품의 AI 출력 품질**이다. Probe 참가자의 공식 점수를 예측하는 도구가 아니다. 일반 웹의 버튼·저장은 `webapp-testing`으로 확인한다.

처음에는 [해커톤용 평가 절차](references/hackathon-eval.md)를 읽고 문제에 맞는 작은 평가 세트를 만든다. 실제 모델을 실행하기 전에는 계획, 사람이 읽기만 한 결과는 수동 검토로 표시한다.

- 기존 프로젝트의 모델·호출 경로·허용된 데이터로 평가한다. 새로운 유료 서비스·모델이나 LangSmith 업로드를 기본으로 요구하지 않는다. 이 묶음에 API 키나 실행 모델은 포함되지 않는다.
- 원본 Quick Start와 `references/details.md` 코드는 **설명용 패턴**이며 즉시 실행 가능한 검증된 평가 프로그램이 아니다. 정의되지 않은 함수, 입력 인자 불일치, 버전별 API 차이가 있으므로 필요한 부분만 현재 환경에 맞춰 구현·실행한다.
- 임베딩·NLI 모델의 영어 예시는 한국어에 그대로 적용하지 않는다. 라벨 매핑·입력 형식·지원 언어와 설치 비용을 확인한다. NLI 점수나 유사도만으로 사실성을 확정하지 않는다.
- BLEU/ROUGE는 표현의 겹침을 측정하며 사실성의 직접 증명이 아니다. perplexity는 정답 여부나 신뢰도를 뜻하지 않는다. LLM 심사 결과에는 심사 기준과 판정 주체를 표시하고 일부 사례를 사람이 대조한다.
- 같은 사례를 두 버전에 넣으면 대응 비교다. 원본의 독립표본 예제를 무조건 적용하지 않는다. 작은 표본으로 통계적 유의성·현업 개선율을 단정하지 않고, 분모가 0이거나 실행 실패인 경우 별도로 처리한다.
- 외부 서비스 예시는 선택 참고 자료다. 자동 데이터 전송·모델 다운로드·프로젝트 재설계는 하지 않는다. 예제의 모델명은 현재 사용할 수 있다는 보장이 아니다.

요청 예: `$llm-evaluation 우리 AI 기능의 정상·근거 없음·모호한 질문 사례로 작은 평가 세트를 만들고, 같은 입력으로 변경 전후를 비교해줘. 실제 출력과 판정 근거, 미실행을 구분해줘.`
