# Codex / Probe 사용 안내

원본: https://github.com/obra/superpowers/tree/main/skills/systematic-debugging
고정 버전: `2ce8aa15d05bd57213e6f746f953aafb7ded7a8b` · MIT, Jesse Vincent.
2026-10-31: 독립 실행을 위해 다른 Superpowers 스킬의 필수 호출을 제거하고, 반복 실패 시 재평가·검증 안내를 조정했다. 원본의 검증 시나리오와 제작 로그는 제외했다.

오류가 났을 때 **재현 → 근거 수집 → 원인 가설 → 작은 수정 → 같은 조건 재검증**에 사용한다. 이미 성공한 작업을 이 스킬 때문에 다시 진행하지 않는다.

- 기본 흐름은 별도 플러그인 없이 현재 프로젝트의 로그와 테스트로 진행한다. Superpowers 전체 설치, 자동 훅, 병렬 에이전트는 필요하지 않다.
- 규모에 맞는 최소 재현과 검증을 사용한다. 사소한 문구 수정에 테스트 프레임워크를 새로 만들지 않는다.
- 세 번 실패했다는 사실만으로 구조가 잘못됐다고 확정하지 않는다. 시도한 가설·반증·현재 남은 조건을 정리하고 접근을 다시 선택한다. 이미 위임된 진단은 계속하며, 목표·범위를 바꿔야 할 때만 참가자의 판단을 구한다.
- 진단 출력에는 비밀키나 실제 고객·현업 데이터를 그대로 기록하지 않는다. 참고 문서의 과거 테스트 수치와 개선율은 원저자의 사례이며 이 묶음의 성과가 아니다.
- `find-polluter.sh`는 Bash와 npm 테스트가 있는 프로젝트용 선택 도구다. Windows에서는 사용할 셸과 테스트 명령을 확인한다. 설치만으로 실행하지 않는다. 실패한 테스트의 상세 결과는 원래 테스트 명령으로 따로 확인한다.

요청 예: `$systematic-debugging 저장 오류를 재현하고 원인 가설을 근거로 좁혀줘. 최소 수정 후 같은 입력으로 다시 확인하고 evidence.md에 결과를 연결해줘.`
